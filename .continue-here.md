## Gotchas
- **Never concatenate `C.*` with hex alpha.** `C.accent` is now `'var(--tg-accent)'`; `${C.accent}55` yields invalid CSS. Use `alpha(C.accent, 33)`.
- `color-mix` is supported in Chromium 111+ / Safari 16.4+ / Firefox 113+ (early 2023). Tauri v2 WebView2 is Chromium — fine.
- Cinematic CSS is gated on `.app-shell` / `.app-sidebar` / `.app-main` selectors. Until those class names land in App.tsx, cinematic will look like "refined with darker colors" instead of floating glass.
- FilePanel now imports `../Graph/constants` — if reorganizing folders, fix the path.
